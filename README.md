Notes: The python AI_Training_ChatbotProject file is used to
train the model in google collab and start a server to use as a backend API.

You need to have your own OPENAI_API_KEY to run the model training portion.
You need to have your own Ngrok auth token YOUR_AUTH_TOKEN to run the Ngrok portion.
Put these as secret keys in google collab with the name above.

Unity needs to be installed to run the Unity portion of the project. Fill in the API call field in the APICall node(Given when starting ngrok).
APICall field needs "/ask/" appended to the end.
Run the game and ask away.
